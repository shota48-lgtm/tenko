## 記録
### 作業1: 吹き出しの案を確定（完了）

- 案A（Canvasに描く）を削除。`drawBubbles` を消し、頭上の「メモあり」の印だけを描く `drawNoteMarks` に置き換えた
- 切り替えのUIを画面から外した。案Aへ到達する経路は残っていない
- 見た目を村に寄せた: 角丸なし（`rounded` を外し1pxの直角）、背景 `#f6f1e3`（クリーム寄り）、
  枠線は `stone-900` の1px、文字は11px、影を1pxだけ付けてドット絵に馴染ませた
- **位置を直した。** 人物の頭の真上に中心を合わせる。
  配置計算の「見込み幅」ではなく実際の枠幅で中心を取りたいので `translate(-50%, -100%)` を使い、
  人物と吹き出しの距離を3ドットから1ドットに詰めた
- **画面の端の扱いを決めた。** 端では中心合わせをやめ、枠を村の内側に寄せる（左端なら左揃え、右端なら右揃え）。
  実機で左端の吹き出しが切れていたのを見て直した

### 作業2: 機能1の主張を成立させる（完了）

村の右に全員分の一覧を置いた。村は3件のまま。

- 各行は「名前 / 状態 / 今日やること」。未記入の人も「未記入」と出す
- 並びは 会話中 → 在席 → 休憩中 → 離席 → 村にいない
- 村と同時に見える（別ページに飛ばさない）
- 長い本文は2行で切る（`line-clamp-2`）。全文は `title` 属性で読める
- 利用者の一覧は `GET /api/users`（表示名のみ。役割・上長・勤怠は返さない）

**20人で実測**（`scripts/seed-crowd.js`）: 一覧26人がスクロールで収まり、村は吹き出し3件のまま崩れなかった。

### 作業3: ヘッダの作り直し（完了）

作り直す前は、5行すべてが素のテキストだった。原因は Tailwind のリセットで、`button` と `input` の
枠・背景が消えていたこと。**画面を見るまで気づけなかった。**

- ボタンに枠と背景を付けた。選択中は黒地に白抜き（`aria-pressed` も付けた）
- 「今日やること」の入力欄に枠と背景と説明ラベルを付け、文字数（46/80）を横に出した
- ラベル（読むもの）は小さい灰色、操作（押すもの）は枠付きに分けた
- 接続状態は点付きのバッジにした（接続中は緑、切断は琥珀）
- **開発用（見た目のA/B/C、部屋数、村の人数）は `?debug=1` のときだけ出す。** 実機で確認済み
- 行数は5行から2行に減った（開発用を除く）

### 作業4: 同じ利用者の複数接続（完了）

**採用する接続の規則: 最後に状態を申告した接続。**
理由は、手元で操作している端末が最後に申告するため。放置された古い端末の「在席」で上書きされない。

- `ws-server` の `presenceList()` で利用者IDごとに畳む。接続数も併せて配る
- 片方を閉じても、もう片方が生きていれば村から消えない（畳んだ結果に残る）
- 接続は拒否しない
- クライアント側でも畳む。古いサーバーに繋いだ場合に同じ利用者が2人描かれ、
  React の key が重複してエラーになる（実機のコンソールで発見）

**実測**: 2つのタブから同じ利用者で接続 → 村の人物は1体、吹き出しも1つ。
