# PHASE47_LOG

tenko Phase 4.7（村を中心にした画面構造への作り直し）の作業ログ。

## ブラウザ操作が使えたか

**使えました。** 1つ直すごとにスクリーンショットを撮って確認しています。

## 調べた実在プロダクト

| 調べたもの | 分かったこと | tenko に採り入れたか |
|---|---|---|
| oVice（公式ブログ・使い方ガイド） | 作業中にすると「アバターは半透明になりリングが赤色となります」。ステータスは画面の機能から切り替える | **採り入れた。** 状態を足元のリングの色で示す形にした。ただし半透明は採らない（村の絵が暗くなり、誰がいるか読みにくくなるため） |
| oVice（設計担当の調査） | 「声掛けNG」を名前の前に表示できる | **採り入れた。** 「集中中」「後で」を名前の前に小さなラベルで出す。既定の「話しかけてOK」は出さない（全員に付くと画面が埋まる） |
| oVice（設計担当の調査） | 2023年6月にアバターを1.6倍に拡大。理由は表情が見やすくなるため。名前に背景色が付いた | **採り入れた。** 人物を2倍にし、名前に濃い背景を付けた。1.6倍にしなかったのはドット絵が整数倍でしか綺麗に拡大できないため |
| oVice | 操作は画面下部のコントロールツールバー | **一部だけ採った。** 状態の変更はアバターのメニューへ、画面の移動（勤怠・承認）だけ下部に置いた。状態を下部に置くと「操作がヘッダにある」問題が下に移るだけになる |
| oVice | ステータスメッセージを自分で設定できる | 既に「今日やること」がある。アバターのメニューから編集する形に移した |

**そのまま真似なかった点**: oVice は音声通話が中心で、アバターの距離が音量に対応する。
tenko は勤怠が中心で、位置は状態が決める（自由移動しない）。距離の概念を持ち込まなかった。
